## 🚀 Deploy NOW (Choose One)

### Option 1: Cloudflare Pages via GitHub (5 min)

1. **Create repo on GitHub:**
   - Go to https://github.com/new
   - Name: `theophysics-web`
   - Public
   - Create

2. **Push your code:**
```powershell
cd d:\GitHub\theophysics-web
git remote add origin https://github.com/YourUsername/theophysics-web.git
git branch -M main
git push -u origin main
```

3. **Deploy on Cloudflare:**
   - https://dash.cloudflare.com
   - Pages → Create project
   - Connect to Git → Select `theophysics-web`
   - Framework: **Vite**
   - Build: `npm run build`
   - Output: `dist`
   - **Deploy!**

**Your site will be live at:** `https://theophysics-web.pages.dev`
